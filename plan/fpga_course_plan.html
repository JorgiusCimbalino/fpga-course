How the 16 UCF sessions fit

Do the official video, quiz and lab for each Day. Two UCF sessions per self-study week; then add the professional extensions.

UCF Days 01–04 · Your weeks 1–2

RTL and digital foundations

Hardware thinking, combinational operators, procedural logic, counters, clocks and resets. Nandland provides short explanations of fundamentals.

UCF Days 05–08 · Your weeks 3–4

Sequential design and testing

Debouncing, automated testbenches, FSMs, hierarchy, parameters and generated modules. Add targeted HDLBits refreshers rather than starting over.

Architecture and interfaces

RAM/ROM/BRAM, arithmetic, performance–power–area trade-offs, UART TX/RX, SPI and protocol testing. Extend later with FIFO and ready/valid.

About the hardware: UCF's original course assumes the Nandland Go Board (iCE40 HX1K). Core Verilog and simulated tests transfer to other boards, but pin constraints, device build arguments, USB/programming and peripherals may differ. Use the board-specific guide below before attempting a hardware lab. This personal study plan is independent of UCF and does not grant university credit or certification.

Evidence of your skills

Three progressively stronger projects

Not just HDL exercises: engineering-quality specifications, tests, reports and documentation.

For each repository: include a specification, block diagram, clean RTL, a testbench, automated run commands, verification results, a synthesis/timing report and a limitations section. Hardware recordings are useful but optional.
Physical lab · Optional in the first weeks

Choose a board and adapt the labs

Different boards can run the same portable RTL, but build tools, connectors, clock speeds, constraints and peripherals are not interchangeable.

Buying advice: The Nandland Go Board is the only zero-adaptation choice for the original UCF hardware labs. The iCEBreaker has the right tools and useful peripherals but the EU seller currently lists it as out of stock. Alchitry Cu is another EU-distributed iCE40 option. UPduino dispatches from the USA; the Olimex low price excludes programmer and supply. The Tang Nano uses Gowin, not Lattice iCE40. Compare your delivered price including VAT, freight, accessories and any customs-processing fees before ordering.

Practical setup · Windows, Linux, macOS

Toolchain and first study session

Set up simulation before buying any hardware. UCF uses Nix to provide a reproducible open-source environment.

Step 1 · Start free

Study the UCF setup guide

Install Icarus Verilog, Yosys, nextpnr-ice40 and GTKWave using the course's supported Nix environment. Windows learners should follow its WSL2 instructions. If hardware USB access is difficult in WSL, simulate in WSL and program from the host using board-appropriate tooling.

UCF Get Started ↗
Step 2 · Follow the daily order

Video → quiz → lab → review

The course provides pre-class material and lab exercises, with quizzes for the teaching sessions; Days 15–16 focus on building and demonstrating the project. In the 16-week roadmap, do two Days per week during the first eight weeks. Read Nandland only when a concept needs a clearer explanation.

View 16-session map ↗
Step 3 · Use source control

Keep everything reproducible

Maintain rtl/, tb/, constraints/, reports/ and a README. Use a Makefile or scripted run commands. Record exactly which board and FPGA part you targeted.

Step 4 · Apply for junior roles

Show evidence, not only certificates

Use the final weeks for professional timing, CDC, commercial tooling, a small amount of VHDL, automated verification, an independent capstone, and an interview-ready project report.

Optional resources: Nandland FPGA-101 · Nandland Verilog · 01signal timing/CDC · cocotb tests. Material and vendor prices checked in November 2026; availability can change.
